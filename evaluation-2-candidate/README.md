# Evaluation Metric Catalog 2.0 machine candidate

This package generates and tests a standalone `agentops.evaluation.metric-catalog@2.0.0` review candidate from the immutable published 1.0.0 baseline. It removes two undefined metrics and replaces the three cost metrics' invented cost-basis semantics with exact recorded Usage compatibility.

It is a review candidate, not a publication record. `npm test` regenerates the checked-in machine artifacts and exercises positive and fail-closed cases. The sibling `evaluation` package is never modified.
